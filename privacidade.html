Política de privacidade

Última atualização: 30 de outubro de 2026

O Rytm é um app para Windows de tarefas e cronômetro. Esta página explica quais dados ele usa, onde eles ficam e como remover o acesso.

Onde seus dados ficam

Tudo o que você cria no Rytm (tarefas, notas, comentários, anexos, histórico de tempo, gravações e configurações) fica no seu computador. Não existe servidor do Rytm: nenhum dado seu é enviado ao desenvolvedor nem a terceiros. O app não tem anúncios nem coleta estatísticas de uso.

Sincronização pelo Google Drive (opcional)

Se você conectar uma conta Google, o Rytm guarda uma cópia dos seus dados numa pasta chamada Rytm no seu próprio Google Drive, para manter seus computadores iguais.

  • O Rytm pede só a permissão drive.file: ele enxerga apenas os arquivos que ele mesmo criou. Os outros arquivos do seu Drive ficam inacessíveis para ele.
  • Ele também lê o nome e o e-mail da conta conectada, só para mostrar nas Configurações qual conta está em uso.
  • Os dados vão direto do seu computador para o seu Drive, pelos serviços do Google.
  • O acesso à conta fica guardado no Gerenciador de Credenciais do Windows, no seu computador.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado. Os dados não são vendidos, compartilhados nem usados para anúncios ou para treinar modelos de IA.

Gravações de reunião

A transcrição das reuniões acontece no seu computador, sem mandar o áudio para a internet. O áudio só vai para o seu Drive se a sincronização estiver ligada.

Como remover o acesso e os dados

  • No Rytm: Configurações › Sincronização › desconectar.
  • Na sua conta Google: myaccount.google.com/permissions › Rytm › Remover acesso.
  • Para apagar a cópia no Drive, exclua a pasta Rytm. Para apagar os dados do computador, desinstale o Rytm e apague a pasta %APPDATA%\com.pedro.rytm.
